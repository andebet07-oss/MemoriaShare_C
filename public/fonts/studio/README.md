# Frame studio fonts

The fonts offered in the frame studio (`/admin/studio`), self-hosted so the editor and the
exported print PNG use the same glyphs on every machine. Loaded only on the studio pages,
through `src/studio/fonts/studio-fonts.css`; the browser downloads a file only when a
design uses that family, weight and script.

Generated by `scripts/studio/gen-fonts.mjs` from the list in `src/studio/fonts/registry.js`:
the Google Fonts `hebrew` / `latin` (and `latin-ext` for Latin-only families) subsets, woff2,
from the @fontsource 5.3.0 releases. All are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling and redistribution.
